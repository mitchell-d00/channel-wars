# Channel Wars — Classic & Modern 📺

A **single-file offline TV station management game** with two player-selectable editions, for iPad, phones and desktop.

## Play
Open [`index.html`](index.html) in your browser—everything is built into this one file. No installation, accounts, or external assets needed.

[Play on GitHub Pages](https://mitchell-d00.github.io/channel-wars/) (when enabled).

## Choose an edition on the start screen

- **Classic Edition:** An original retro pixel-art TV building with eight navigable floors, character portraits and dialogue, illustrated office scenes and old-school controls.
- **Modern Edition:** The touch-friendly Channel Wars dashboard, broadcast analytics and cinematic story panels.

The two editions share **one station, one schedule, one set of finances, and one saved game**. Choose each time you launch or switch using the ◈ button or **⚙ Settings → Game edition**.

## Gameplay
Buy licenses for 32 fictional programs, schedule seven TV hours daily, negotiate sponsor contracts, compete with three rivals, produce news, upgrade equipment, borrow funds, and track ratings. Name your own channel or randomize it; edit show names in Settings or import/export a `.txt` title list.

### Import your own show names

Under **⚙ Settings → TV show name editor**, use **Save as .txt**, edit names, and **Upload .txt**:

```text
starlight = Neon House
midnight = Mystery District
cosmos = Galactic Horizons
```

Save data stays in the browser, with import/export JSON for backup. Earlier Channel Wars saves remain compatible.
